# CSE3200 Lab05 MyBlipBlop App
This is a TikTok copy made in Android Studio using Android Jetpack and Media3 ExoPlayer.

It has the basic functionalities of what the TikTok app has, swiping into a different video, video loops after finishing, and when rotating to landscape, it stays in portait mode.  

The videos are hardcoded into the app and sourced from:  
- [paytane](https://www.papytane.com/mp4/)
- [Nasa Image and Video Library](https://images.nasa.gov/)
- [Internet Archive](https://archive.org/)
- [Imgur](https://imgur.com/)
- [my-meme-folder](https://github.com/Dominicentek/my-meme-folder) (by Dominicentek)
